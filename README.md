# 우리끼리 오락실

게임 선택 홈페이지(`/`)와 실시간 초성 폭탄(`/bomb`). 스도쿠 아레나와 베이스볼 아레나의 기존 배포 주소로 연결합니다.

## 초성 폭탄
- 로그인 없이 2–8인 초대방. 첫 입장자가 방장입니다.
- 한글 두 글자, 게임 전용 단어장에 등록된 단어만 정답으로 인정합니다. 전체 국어사전이 아닙니다.
- 서버가 초성/정답/시간/생명을 판정합니다. 정답이면 다음 선수에게 새로운 초성과 시간(10/15/20/30초)을 줍니다.
- 기본 15초, 생명 3개. 오답은 재입력 가능, 시간 초과나 포기는 생명 1개 감소, 마지막 생존자 승리.
- 한 경기 중 중복 단어 불가. 사용 가능한 전체 단어가 소진되면 사용 목록을 새로 시작합니다.
- 채팅, 관전, 재경기, 같은 기기/브라우저 자동 복귀 지원. 모두 연결이 끊기면 일시 정지하고 복귀 시 해당 차례 시간을 새로 줍니다.
- 메모리 기반이므로 서버 재시작 시 방/기록은 초기화됩니다.

## 실행
Node.js 20 이상. `npm ci`, `npm start`. `PORT` 기본 3000. `npm test`로 판정/단어장/시간 경계/8명 탈락 검사.
Render 무료 Node web service: build `npm ci`, start `npm start`.

## 라이어 클럽
- `/liar`: 로그인 없는 4–10인 초대방. 라이어 1명, 시민에게만 같은 제시어 전달.
- 5개 주제 × 16개 제시어. 랜덤 주제와 두 바퀴 힌트가 기본. 힌트 순서 무작위.
- 힌트 → 채팅 토론 → 비밀 투표. 동률 1회 재투표, 다시 동률이면 라이어 승리.
- 라이어 지목 시 정답 추측 1회로 역전 가능. 자기 투표·중복 투표·지난 경기 요청 차단.
- 역할과 표는 서버에서 참가자별로 필터링. 서버 소스·제시어 목록 파일은 정적 제공하지 않음.
- 같은 브라우저의 같은 링크에서 인증 토큰으로 복귀. 연결 끊긴 차례/미투표자/라이어는 30초 대기 후 방장이 건너뛰거나 집계·종료할 수 있음. 접속자에게는 시간제한 없음.
- 채팅·재경기·대기실, 첫 입장자 방장 및 방장 이탈 시 자동 위임. 최대 인원인 대기실은 접속 끊긴 사람의 자리를 신규 입장자에게 내줌.
- 메모리 방은 서버 재시작 또는 전원 연결 해제 후 1시간 경과 시 초기화.
- 검증: `npm test`, `node liar-multiplayer-check.mjs` (10 WebSocket clients).
